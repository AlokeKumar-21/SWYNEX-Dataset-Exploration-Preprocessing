# SWYNEX — Dataset Exploration & Preprocessing

## Overview
This project completes Task 1 of my machine learning internship at SWYNEX Technologies. It explores and preprocesses the IBM Telco Customer Churn dataset.

## Objectives
- Perform exploratory data analysis (EDA).
- Identify missing values and duplicate records.
- Clean data types and handle missing values.
- Encode categorical features.
- Prepare training and testing datasets.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## How to Run
1. Clone this repository.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Open `dataset_exploration.ipynb` in VS Code or Jupyter.
4. Select a Python kernel and run the cells in order.
